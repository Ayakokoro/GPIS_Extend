# 完整 shaderball SDF 的固定格点 GPIS 渲染

打开 [Shadertoy 编辑器](https://www.shadertoy.com/new)，将 [lattice-cubic-gpis.glsl](lattice-cubic-gpis.glsl) 全文粘贴到 **Image**，点击编译。使用单个 WebGL 2 片元着色器，无需设置输入通道、纹理或 Buffer。

左侧 **MEAN** 显示原场景的 shaderball 均值场，右侧 **GPIS** 给同一个场加入沿线格点噪声。球壳、内球、刻槽和带切口的底座都参与同一次首次碰撞搜索。在球壳遮住底座的位置，最先穿过哪个部分就显示哪个部分。底座也会随种子改变轮廓和法线。未命中的射线显示环境背景。

相机缓慢转动。点击或拖动球体或底座可选中一条正交射线，两侧的圆环标出这条射线在图上的位置。底部横轴是从射线起点量起的世界距离，短刻度是噪声格点，纵轴是场值。虚线为均值，琥珀色实线为总场，珊瑚色标记为有效窗口内的首次命中。[单实现预览](../../../outputs/shadertoy/lattice-cubic-gpis.png)

默认保守模式在 Intel UHD Graphics（0xA788）上用 Edge WebGL 2 / ANGLE D3D11 测量，预热 6 帧后的 24 帧中，完整 Image pass 的 GPU 耗时中位数为 16.52 ms（640 × 360）和 29.73 ms（960 × 540），包含两个面板和射线曲线。

## 均值场与坐标

几何来自 Tungsten 的 `SdfFunctions::knob`。原始烘焙网格以世界坐标 $(0,0.8,0)$ 为球心，在 $609^3$ 个结点上采样完整 CSG 函数，体素边长为 $0.005$。GPU 使用局部坐标 $p=x_{\rm world}-(0,0.8,0)$。源网格的世界原点约为 $(-1.52,-0.519,-1.52)$，对应展示坐标约为 $(-1.52,-1.319,-1.52)$。着色器按该原点和体素大小定位八个角点，用与烘焙相同的几何公式按需生成结点值，再进行三线性插值。这样两种 Shadertoy 入口都能重建完整均值场，参数和求值使用 WebGL 的单精度浮点数。[源几何](../../../src/core/math/SdfFunctionsQueries.cpp#L245) · [场景配置](../../example-scenes/lattice-cubic-gpis/shaderball.json) · [网格变换和烘焙记录](../../../outputs/shaderball_vdb_ray_profiles_20261117/fields/shaderball.nvdb.json)

原场景过程包围盒的世界范围约为 $[-1.5,1.5]\times[-0.499,2.501]\times[-1.5,1.5]$，四层体素缓冲将它与网格边缘隔开。求交窗口取有限展示射线与该包围盒的交段。画面中只有这一份 GPIS 几何，底座包含在这份 SDF 内。工作室着色仅使用首碰位置和法线，空射线直接取背景色。

在 Intel UHD 的 WebGL 2 上读回 GPU 均值，与 Tungsten 读取原始 `shaderball_sdf.vdb` 的结果逐点对照。271 个格点的最大绝对差为 $2.98\times10^{-7}$，另取的 271 个体素内点为 $2.09\times10^{-7}$，单位与 SDF 相同。

## Ensemble 渲染

要看同一个视角下多条随机实现的平均图像，使用 **Buffer A + Image** 两个标签页，各自的 `iChannel0` 都选 **Buffer A**。两页使用相同的分辨率，不需要 Common 或外部纹理。

| Shadertoy 标签页 | 粘贴的代码 | `iChannel0` 的作用 |
| --- | --- | --- |
| **Buffer A** | [已配置的 Buffer A](../../../outputs/shadertoy/ensemble/buffer-a.glsl) | 读取上一帧积累的线性颜色和样本数 |
| **Image** | [ensemble-image.glsl](ensemble-image.glsl) | 显示本帧 Buffer A 的结果 |

Buffer A 与原单通道实现共用一份源文件。也可直接在 **Buffer A** 中粘贴 [lattice-cubic-gpis.glsl](lattice-cubic-gpis.glsl)，并在第一行加上 `#define ENSEMBLE_BUFFER`。运行后，**SINGLE** 固定显示第一个实现，**ENSEMBLE** 每帧增加一个随机实现，默认在 `N=128` 时停止累积。[128 个实现的预览图](../../../outputs/shadertoy/ensemble/ensemble-128.png)

每个像素固定相机射线。第 $k$ 个种子产生一次完整的噪声实现，求出整个 shaderball 的可见首碰并着色，得到线性 RGB 辐射亮度 $L_k$。未命中时取背景亮度。反馈纹理保存运行均值。

$$
\bar L_1=L_1,\qquad \bar L_{n+1}=\bar L_n+\frac{L_{n+1}-\bar L_n}{n+1}.
$$

Image 对均值只做一次曝光和显示转换。同一实现的种子由所有像素共用，相邻平行射线通过下文的高斯系数旋转相关。每一帧固定像素位置、灯光与材质，平均不同 GPIS 实现的单次首碰着色。

点击任一面板选择射线。底部 **HIT CDF** 显示 $\widehat P(T\le t)=\#\{k:T_k\le t\}/n$。$T_k$ 是这条射线在有效窗口内首次命中完整 GPIS 的距离，从展示射线起点计量。先命中底座也算命中。未命中按 $T_k=+\infty$ 计入分母，因此曲线在最右端可以低于 1。珊瑚色虚线标出左图实现的首碰位置。移动探针只重置这条射线的统计。上部图像保持自己的样本数。

在默认视角和 $960\times540$ 分辨率下比较前两个 ensemble 种子，按命中位置处的原始几何分支判断归属。两次都命中底座的 19,806 条像素射线中，首碰距离绝对变化的中位数为 $0.18705$ 个世界单位。例如左面板像素 $(119,181)$（从左下计）的首碰从 $2.33624$ 变为 $2.52330$。

在 Buffer A 中改 `ENSEMBLE_TARGET` 可调整样本数（1–1024），改 `ENSEMBLE_VIEW_TIME` 可选一个固定相机角度。相机在一次累积中保持静止。改种子、核参数、上述模式或画面分辨率后会重新累计；编辑几何或着色函数后，使用 Shadertoy 的重启按钮从第 1 帧重新计算。

## 可改参数

修改 shader 顶部的常量或开关后重新编译。

预览沿用此前展示的噪声幅值和相关长度，以便比较更换几何前后的效果。要使用仓库中 shaderball 场景的平稳核参数，可将 `SIGMA` 设为 `0.02`，将 `SPACING` 设为 `0.10`，此时 $\ell=0.20$。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `REALIZATION` | `23u` | 改种子即可换一组完整实现。 |
| `SIGMA` | `0.082` | 控制噪声幅值，设为零可比较两侧的相同几何。 |
| `SPACING` | `0.11` | 沿射线的噪声格距。平稳模式的相关长度为两倍格距，即默认 $0.22$。调整格距时，覆盖完整过程包围盒的展示射线长度固定为 $5.72$。 |
| `NONSTATIONARY` | `0` | 设为 1 时，相关长度从 2 个格距平滑变到 3.4 个格距，幅值从 0.65 倍升到 1 倍。权重和斜率包含这两个参数的变化。 |
| `THREE_SIGMA` | `0` | 默认按已生成噪声段的 Bézier 控制值保守判空。设为 1 时，再用场景幅值上界的三倍提前跳过正侧区间，可能漏掉尾部穿越。 |
| `CONDITION_STATIONARY_BIRTH` | `0` | 在平稳模式设为 1，可令出生点的噪声值与物理方向斜率都为零，即总场在起点匹配均值和均值斜率。 |
| `SMOOTH_MEAN_NORMALS` | `1` | 默认用生成均值格点的连续函数平滑着色法线。设为 0 会显示三线性体素的分片梯度。求交和诊断曲线始终使用同一三线性场。 |

## GPU 上实际计算了什么

1. 每条射线通过整数哈希和 Box–Muller 按源格编号生成高斯系数。平稳模式复用预存的 SE 权重，非平稳模式在格段两端重新计算局部权重和沿线导数。两种模式都用端点的值和斜率组装一个三次 Hermite 噪声段。
2. 对单位射线的一段 $[a,b]$，设 $p_m$ 为区间中点，$g$ 为连续 shaderball 函数，$h=0.005$ 为体素边长。连续函数的 Lipschitz 上界为 $L=1.04$，对应的三线性场在整段上的下界可取 $m_-=g(p_m)-L((b-a)/2+\sqrt{3}h/2)-10^{-5}$。第一项距离补偿中点到段端的变化，第二项补偿角点三线性插值误差，末项是普通浮点运算余量。令 $c_0,\ldots,c_3$ 为这一噪声段的 Bézier 控制值，若 $m_-+\min_i c_i>0$，整段可跳过。其余区间再按斜率界跳过正值前缀，进入细体素遍历。在噪声段与体素的每个交区间内，总场是三次式。在其内部驻点处分出单调区间后，用普通 float 二分定位首个下穿。窗口入口已有负值时，直接记录入口距离。
3. 为了让轮廓和选中射线容易追踪，相邻平行射线共用随机数，对每对标准高斯系数按屏幕位置做确定性的二维旋转。旋转保持单条射线上每对系数的标准高斯分布，同时规定跨射线的相关性。旋转角的横向导数也参与右侧表面的着色法线。该展示采用沿线 GP 的这种跨射线耦合。
